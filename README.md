# Data for review

*Coercibility and Leverage: Evidence from China–Southeast Asia Economic Relations*

This repository holds the country-year panel behind the manuscript, shared for peer review. It contains derived values only; the raw inputs are not redistributed.

| File | Contents |
|---|---|
| `celi_panel_2010_2023.csv` | The leverage index (CELI), the exposure index (CEEI) and their components for the ten ASEAN states, 2010–2023: 140 rows, one per state-year, 31 columns |
| `CODEBOOK.md` | What each column measures |
| `INPUTS.md` | The sources of the inputs and how to obtain them |

The file reproduces the figures reported in the manuscript. A full replication package, with code, will be deposited with a DOI on publication. Please do not redistribute the data while the manuscript is under review.
